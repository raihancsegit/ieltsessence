# IELTS Essence

A modern, comprehensive IELTS preparation & study abroad platform built with Next.js, React, Tailwind CSS, and Lucide Icons.

## Features
- 📚 Comprehensive Course Pages (Writing, Speaking, Crash Course, Foundation)
- 🧮 Interactive IELTS Band Score Calculator
- 📝 Writing Assessment & AI Evaluation Module
- 🌍 Study Abroad Consultation & University Finder
- 🎯 Dynamic Responsive UI with Smooth Micro-animations
- ⚡ Ultra-fast performance powered by Next.js 15 App Router

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
